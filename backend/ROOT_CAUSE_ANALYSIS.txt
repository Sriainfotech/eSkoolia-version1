3. ROOT CAUSE - EXACT EXCEPTION
═══════════════════════════════════════════════════════════════════════════════

Exception Type: AttributeError
Exception Message: 'AnonymousUser' object has no attribute 'school_id'

Location: backend/apps/tenancy/views.py, lines 57-68 (debug print statements)

Exact Failing Line:
  print("SCHOOL ID:", request.user.school_id)

The issue is:
1. When an AnonymousUser accesses school_info_view, request.user is AnonymousUser
2. AnonymousUser doesn't have 'school_id' or 'school' attributes
3. Accessing these attributes throws AttributeError
4. The broad except Exception block catches this error
5. Returns {"error": "School not found"} instead of the actual response

5. IMPACT ANALYSIS
═══════════════════════════════════════════════════════════════════════════════

This affects:
✗ Anonymous users accessing school_info_view endpoint
✓ Authenticated users (they have school_id attribute)

Flow:
  AnonymousUser → school_info_view() → debug prints → AttributeError → 
  exception handler → {"error": "School not found"}

Authenticated users bypass this because User objects have the school_id 
attribute, so the debug prints don't fail.


═══════════════════════════════════════════════════════════════════════════════
6. WHY LOGIN SUCCEEDS BUT APIs FAIL
═══════════════════════════════════════════════════════════════════════════════

Login flow:
1. User submits credentials
2. Backend authenticates user
3. Returns token to frontend
4. Frontend stores token

Frontend API calls:
1. Calls school_info_view WITHOUT authentication (public endpoint)
2. Request has AnonymousUser
3. Debug prints fail with AttributeError
4. Returns "School not found" error

This explains why:
- school_info_view fails with AnonymousUser (404 error)
- Other authenticated APIs might also fail if they access user attributes 
  in debug code before proper tenant initialization

@api_view(["GET"])
@permission_classes([AllowAny])
def school_info_view(request):
    """Public endpoint — returns school branding info for the login page."""
    subdomain = request.query_params.get("subdomain", "").strip().lower()
    if not subdomain:
        return Response({"error": "subdomain query parameter is required"}, status=400)

    try:
        from apps.tenancy.models import Domain
        
        # DEBUG PRINTS (PROBLEMATIC)
        print("=" * 50)
        print("REQUEST USER:", request.user)
        print("USERNAME:", request.user.username)
        print("SCHOOL ID:", request.user.school_id)  # ← FAILS FOR AnonymousUser
        print("SCHOOL:", request.user.school)        # ← FAILS FOR AnonymousUser
        print("HOST:", request.get_host())
        print("TENANT:", getattr(request, "tenant", None))
        print("SUBDOMAIN PARAM:", subdomain)
        print("=" * 50)
        
        domain = Domain.objects.select_related("tenant").filter(domain=subdomain).first()
        if domain is None:
            domain = Domain.objects.select_related("tenant").filter(
                domain__startswith=f"{subdomain}."
            ).first()
        if domain is None:
            return Response({"error": "School not found"}, status=404)
        tenant = domain.tenant
        return Response({
            "name": tenant.name,
            "subdomain": tenant.subdomain_url,
            "logo_url": tenant.logo_url or None,
            "brand_color": tenant.brand_color or "#0d9488",
            "status": tenant.status,
        })
    except Exception:
        return Response({"error": "School not found"}, status=404)
